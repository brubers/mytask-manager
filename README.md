# MyTask Manager

An application developed in Java to practice object-oriented programming fundamentals and learn about Maven project organization.

MyTask Manager is a task management application that handles information such as task ID, title, description, and completion status.

## Features

- Organize tasks using objects.
- Store and manage tasks in a list.
- Display task information.
- Track task completion status.
- Practice object-oriented programming and Java Collections.

## Technologies

- **Java 25** — Main programming language.
- **Apache Maven** — Used mainly to organize the project structure and manage its configuration through the `pom.xml` file. The project does not yet rely on external dependencies or advanced Maven features.

## Learning Goals

This project is part of my Java learning journey. Its main goal is to reinforce concepts such as:

- Classes and objects
- Encapsulation
- Java Collections
- Code organization
